# Business Sales Data Analysis

## 1. Project Overview
This project focuses on analyzing business sales data using Python. The main objective is to understand sales performance, identify top-performing products and categories, analyze customer purchasing patterns, and generate useful business insights.

## 2. Objectives
- Clean and prepare sales data using Pandas.
- Perform Exploratory Data Analysis (EDA).
- Analyze total sales and revenue.
- Identify top-selling products and categories.
- Analyze sales by city, payment method, and sales channel.
- Create visualizations using Matplotlib and Plotly.
- Generate meaningful business insights.

## 3. Tools & Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly

## 4. Dataset Information
The dataset contains business sales transaction details, including:
- Transaction ID
- Order Date
- Customer Details
- Gender and Age
- City and State
- Product Name and Category
- Quantity
- Unit Price
- Discount Percentage
- Sales Amount
- Payment Method
- Sales Channel

## 5. Project Workflow
1. Import Python libraries.
2. Upload and load the Excel dataset.
3. Perform data cleaning.
4. Check missing values and duplicate records.
5. Perform Exploratory Data Analysis.
6. Calculate sales KPIs.
7. Analyze sales using grouping and aggregation.
8. Create charts and visualizations.
9. Generate business insights and conclusions.

## 6. Key Performance Indicators (KPIs)
- Total Sales
- Total Transactions
- Total Quantity Sold
- Average Order Value (AOV)
- Total Customers
- Total Discount

## 7. Analysis Performed
- Category-wise sales analysis
- Product-wise sales analysis
- City-wise sales analysis
- Monthly sales trend analysis
- Payment method analysis
- Online vs Offline sales analysis
- Top-performing products

## 8. Business Insights
The analysis helps identify:
- Best-performing products and categories.
- Cities generating the highest revenue.
- Monthly sales trends.
- Customer purchasing patterns.
- Preferred payment methods.
- Performance of online and offline sales channels.

## 9. Conclusion
This project demonstrates how Python can be used for business sales analysis. By cleaning, analyzing, and visualizing sales data, useful insights can be generated to support business decisions and improve sales performance.
